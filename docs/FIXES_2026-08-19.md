# Fixes applied on 2026-08-19

This repaired package contains the following corrections discovered during the first local startup:

- PostgreSQL 18 Docker volume uses `/var/lib/postgresql` instead of the obsolete `/var/lib/postgresql/data` mount.
- Predis is declared as the default Redis client for Windows-friendly local development.
- Laravel Tinker is declared as a development dependency.
- Angular `development` and `production` build configurations are defined.
- Deprecated TypeScript `baseUrl` configuration was removed.
- Frontend API URL is aligned with `php artisan serve` at `127.0.0.1:8000`.
- Auth HTTP interceptor no longer injects services that themselves depend on `HttpClient`; tokens are read directly from local storage to avoid a circular dependency during login.
- Platform login displays a connection-specific error when the API cannot be reached.
- Added backend regression tests for platform authentication and tenant-user denial on platform APIs.

After replacing an existing copy with this package, run `composer update` (or `composer install` with the generated lock file), `npm install`, and the normal migration/test commands documented in README.md.
